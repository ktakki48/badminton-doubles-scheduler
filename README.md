# ダブルス対戦メーカー

バドミントンダブルス用の対戦表メーカーです。Safariで開いてiPhoneのホーム画面に追加すると、アプリ風に利用できます。

## 主な機能

- 登録メンバー最大50人の端末内保存
- 開催ごとの当日参加者選択
- 使用コート数・試合数の設定
- レーティングあり／なしの組み分け
- 直近ペア・対戦相手の重複を抑えた対戦表作成
- テキストコピー、テキスト表示、画像出力
- 登録メンバー名簿のJSON出力／読込
- iPhone幅では作成済み対戦表を横スクロールで確認
- PWA対応：ホーム画面追加、オフラインキャッシュ

## V23.1の修正事項

- 対戦表の表示色を改め、カード・文字のコントラストを強化。文字色継承のCSS不具合を修正。
- 対戦結果の領域を画面幅内に固定し、**試合カード部分のみ**横スワイプする表示に変更。
- 大会モードの休憩選定を**個人単位**に変更。固定ペアは両者とも出場する場合のみ一緒に組む。片方だけ休憩するときは出場者をフリー扱いにして組み直す。
- 休憩の公平性を考慮し、固定ペアの継続は履歴のペア重複ペナルティを免除。
- 通常モードの組み合わせロジックは変更なし。端末内のV23設定と名簿を維持。
- PWAキャッシュを `doubles-match-maker-v23-1` に更新。

## V23の追加機能

- 「対戦形式」で通常モードと大会ペア固定モードを切り替えます。
- 大会モードでは登録メンバーから2名を選んで「固定ペアを追加」を押します。登録・解除は端末内に保存されます。
- **2人とも当日参加している場合のみ**、固定ペアとして試合に出場します。片方が不参加ならもう片方はフリー参加者になります。
- 休憩は個人単位で選択します。両名とも出場する固定ペアは必ず同じチームで、片方が休憩中はもう片方がフリーとして他の選手と組みます。レーティングや出場バランスも考慮します。
- モード切替時に表示中の古い対戦結果をクリアします。名簿のバックアップJSONは従来どおり**名簿専用**であり、固定ペアの情報は含みません。固定ペアは同じブラウザ内に保存されます。
- 参加者4人以上で、コート数の範囲内で試合を作成します。固定ペアの都合で休憩が二人同時になる制約はなくなりました。

## ファイル構成

```text
.
├── index.html          # アプリ本体
├── manifest.json       # PWA設定
├── sw.js               # Service Worker / キャッシュ設定
├── icons/              # ホーム画面・PWA用アイコン
├── README.md           # この説明書
├── CHANGELOG.md        # 変更履歴
├── LICENSE             # 権利表記
├── .gitignore          # Git管理から除外するファイル
└── .nojekyll           # GitHub Pagesで静的ファイルをそのまま配信するための空ファイル
```

## GitHub Pagesへの配置方法

1. このZipを解凍します。
2. `index.html`、`manifest.json`、`sw.js`、`icons`フォルダ、README等をリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` で、公開元を `main` ブランチの `/root` に設定します。
4. Pagesの公開URLにアクセスし、Safariで「共有」→「ホーム画面に追加」を選びます。

> 注意：`index.html` がリポジトリ直下にある構成を前提にしています。`doubles-match-maker-v22-2` のようなフォルダごとアップロードする場合は、GitHub Pagesの公開パスが一段深くなります。

## 更新時の注意

Service Workerでキャッシュしているため、更新時は `sw.js` の `CACHE_NAME` を新しいバージョン名へ変更してください。V23では `doubles-match-maker-v23` に設定済みです。

既存ユーザーの端末内データは、V22までの保存キーから読み込めるようにしています。

## 動作環境

- iPhone Safari
- PCブラウザ（Chrome / Edge / Safari相当）
- 静的ホスティング（GitHub Pages等）

サーバー側のプログラムやビルド環境は不要です。
