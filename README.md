# ダブルス対戦メーカー

バドミントンダブルス用の対戦表メーカーです。Safariで開いてiPhoneのホーム画面に追加すると、アプリ風に利用できます。

## 主な機能

- 登録メンバー最大50人の端末内保存
- 開催ごとの当日参加者選択
- 使用コート数・試合数の設定
- レーティングあり／なしの組み分け
- 直近ペア・対戦相手の重複を抑えた対戦表作成
- テキストコピー、テキスト表示、画像出力
- 登録メンバー名簿のJSON出力／読込
- iPhone幅では作成済み対戦表を横スクロールで確認
- PWA対応：ホーム画面追加、オフラインキャッシュ

## V23.3の修正事項（大会モードの休憩ローテーション改善）

- **休憩決定を対戦組み合わせ最適化より優先**するよう変更しました。各回の休憩者は、累計休憩回数が少ない人から必ず選出します。
- 累計休憩回数が同じ場合は、**前回の休憩が最も古い人**から選びます。初回休憩が遅すぎる／休憩直後にまた休むケースを抑制します。
- 14人・3コートなら毎回2名休憩するため、**第7試合までに全員が少なくとも1回休憩**するようになります。休憩回数の最大差は、毎試合終了時点で1回以内です。
- 休憩の優先順位が同じ選手だけランダムに選び、**残った選手についてV23.2の対戦相手・フリーペア分散処理**をそのまま実行します。
- 固定ペアの片方のみの休憩と、通常モード・画面表示・画像出力・保存データ仕様は従来どおりです。
- PWAキャッシュ名を `doubles-match-maker-v23-3` に更新しました。

## V23.2の修正事項（大会モードの組合せ分散）

- 大会モードの組み合わせ方法を、単純なランダム試行から**履歴の集中を評価する探索**に変更しました。
- フリー参加者のペア交換、対戦チームの入れ替えを試行し、対戦相手・同じ4人組・同じチーム同士の再戦を抑制します。
- 同じ相手との対戦回数について二乗ペナルティを導入。複数の相手へ分散しやすくしました。
- 休憩は引き続き個人単位で、出場回数を優先的に均等化します。固定ペアの片方だけが休憩の場合も、もう片方はフリーと組みます。
- レーティングありモードでは、実力差にもペナルティを付けて偏り防止と実力バランスを両立させます。ただし両者にはトレードオフがあり、全試合の実力差が必ず旧版以下になるわけではありません。
- 通常モードの組み合わせ生成方法、画面表示・画像出力・保存キーは変更していません。PWAキャッシュ名を `doubles-match-maker-v23-2` に更新。

## V23.1の修正事項

- 対戦表の表示色を改め、カード・文字のコントラストを強化。文字色継承のCSS不具合を修正。
- 対戦結果の領域を画面幅内に固定し、**試合カード部分のみ**横スワイプする表示に変更。

- 休憩の公平性を考慮し、固定ペアの継続は履歴のペア重複ペナルティを免除。
- 通常モードの組み合わせロジックは変更なし。端末内のV23設定と名簿を維持。
- PWAキャッシュを `doubles-match-maker-v23-1` に更新。

## V23の追加機能

- 「対戦形式」で通常モードと大会ペア固定モードを切り替えます。
- 大会モードでは登録メンバーから2名を選んで「固定ペアを追加」を押します。登録・解除は端末内に保存されます。
- **2人とも当日参加している場合のみ**、固定ペアとして試合に出場します。片方が不参加ならもう片方はフリー参加者になります。
- 休憩は個人単位で選択します。両名とも出場する固定ペアは必ず同じチームで、片方が休憩中はもう片方がフリーとして他の選手と組みます。レーティングや出場バランスも考慮します。
- モード切替時に表示中の古い対戦結果をクリアします。名簿のバックアップJSONは従来どおり**名簿専用**であり、固定ペアの情報は含みません。固定ペアは同じブラウザ内に保存されます。
- 参加者4人以上で、コート数の範囲内で試合を作成します。固定ペアの都合で休憩が二人同時になる制約はなくなりました。

## ファイル構成

```text
.
├── index.html          # アプリ本体
├── manifest.json       # PWA設定
├── sw.js               # Service Worker / キャッシュ設定
├── icons/              # ホーム画面・PWA用アイコン
├── README.md           # この説明書
├── CHANGELOG.md        # 変更履歴
├── tests/tournament-regression.cjs  # Node.jsによる自動テスト
├── LICENSE             # 権利表記
├── .gitignore          # Git管理から除外するファイル
└── .nojekyll           # GitHub Pagesで静的ファイルをそのまま配信するための空ファイル
```

## GitHub Pagesへの配置方法

1. このZipを解凍します。
2. `index.html`、`manifest.json`、`sw.js`、`icons`フォルダ、README等をリポジトリ直下へアップロードします。
3. GitHubの `Settings` → `Pages` で、公開元を `main` ブランチの `/root` に設定します。
4. Pagesの公開URLにアクセスし、Safariで「共有」→「ホーム画面に追加」を選びます。

> 注意：`index.html` がリポジトリ直下にある構成を前提にしています。`doubles-match-maker-v22-2` のようなフォルダごとアップロードする場合は、GitHub Pagesの公開パスが一段深くなります。

## 更新時の注意

Service Workerでキャッシュしているため、更新時は `sw.js` の `CACHE_NAME` を新しいバージョン名へ変更してください。V23.3では `doubles-match-maker-v23-3` に設定済みです。

V23.2からの更新では既存保存キーを維持しているため、名簿・固定ペア登録を引き継ぐ設計です。V22以前の保存データの移行機能も維持しています。

## 動作環境

- iPhone Safari
- PCブラウザ（Chrome / Edge / Safari相当）
- 静的ホスティング（GitHub Pages等）

サーバー側のプログラムやビルド環境は不要です。

## アルゴリズムの動作確認

Node.jsがある環境で `node tests/tournament-regression.cjs` を実行すると、4～50名の大会モード・固定ペア・個別休憩・通常モードの主要な回帰テストを実行できます。
